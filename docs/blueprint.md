# **App Name**: IB-Pro

## Core Features:

- Record Insemination Data: Input and store data for each artificial insemination event, including date, petugas (staff) name, puskeswan (animal health center), peternak (breeder) name, breeder address, phone number, ID (KTP), type of cow, cow ID (Eartag), type of straw, straw ID, straw batch ID, and straw producer. Persist the insemination data to Firestore.
- Retrieve Breeder Records: Quickly find the previous insemination record by breeder's ID or phone number.
- Summarize breeding program: Give advice based on the stored records to optimize the breeding schedule. Summarization performed with AI tool.
- Export Data: Export the collected data in CSV format.

## Style Guidelines:

- Primary color: Soft olive green (#A7C48C), evokes natural health and growth. It is friendly to the eye without being overpowering.
- Background color: Light beige (#F5F5DC), a desaturated olive green that complements the primary color while providing a calm backdrop.
- Accent color: Muted brown (#C4A484), provides contrast and draws the user's attention to actions of interest.
- Body and headline font: 'PT Sans', a versatile sans-serif, for both headers and body text
- Consistent and clear icons related to animal husbandry.
- Clean, well-spaced layout for easy data entry. Should be made consistent with prior 'PuskeswanPro' project, according to the user request.
- Subtle transitions and loading animations for a smooth user experience.
